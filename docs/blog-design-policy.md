# ブログ「MORK STUDIO 開発記」デザイン方針

- 対象：https://mork-studio.hatenablog.com/（はてなブログ無料プラン）
- 元にしたもの：MORK STUDIO デザインシステム（https://claude.ai/artifact/4LE1KiVduBjPHCQqJDiwwC）と、公開中のサポートページ（https://moanoco-mork.github.io/mork-studio/）
- 一緒に置いたファイル
  - `docs/blog/hatena-design.css`：はてなブログの「デザイン CSS」にそのまま貼れる案
  - `docs/blog/sidebar-apps.html`：サイドバーの「MORK STUDIO のアプリ」欄の HTML
  - `docs/blog/eyecatch-template.html`：アイキャッチ画像（1200×630）のテンプレート
  - `docs/blog/eyecatch-sample.png`：テンプレートで作った見本

## 0. 先に守央さんに決めてほしいこと（要確認）

1. **色のトーン**
   スタジオのデザインシステムは、守央さんの指示で「青はアッシュ系、くすんだ彩度を落とした色」にしています（ブーモルの青は `#58708a`）。サポートページもこの色で公開済みです。一方、master からは「ブーモルはアメコミ風のポップ。パステルや灰色の地味な色は好まない」と聞いています。
   この方針では、**ブログの地とスタジオの部分はデザインシステムのくすんだ色**にし、**アプリの色は各アプリが実際に使っている色**をそのまま使います。ブーモルだけはアプリ内の鮮やかな色がまだデザインシステムにないので、いまはアッシュブルーで書いています。ブーモルの鮮やかな色をブログでも使うなら、アプリで使っている色コードを教えてください。追加します。
2. **ブログアイコン（11/15 に入ったもの）**
   紫のグラデーション（`#4f46e5`〜`#818cf8`）と、緑・オレンジ・ピンクの点は、デザインシステムのどの色とも合いません。紫から青紫へのグラデーションは「AI が作ったっぽい」と見られやすい配色でもあります。
   作り直す案：地をアッシュネイビー `#3d4f63`、白い「M」を Dela Gothic One、角丸 14px（の比率）、点はなし。下の「STUDIO」も同じフォントで白。スタジオのロゴ（`MORK STUDIO`、Dela Gothic One、`#3d4f63`）と同じ形になります。
3. **アプリ名の書き方**
   スタジオトップでは「てくてくダイヤリー（TekuTeku）」、ホーム画面の名前は「てくてく」です。ブログでは初出を「てくてくダイヤリー」、2 回目から「てくてく」にします。

## 1. 全体の色・文字・雰囲気

**考え方：地はスタジオの色でそろえ、アプリの色はそのアプリの話をする場所にだけ出す。**
3 つのアプリの色を全部いっぺんに並べると、まとまりがなくなります。そこで、ブログの地・本文・見出し・リンクはスタジオ共通の色にします。アプリの色は「カテゴリ」「サイドバーのカード」「アイキャッチの帯」の 3 か所だけで使います。

### 色

| 名前 | 色 | 使う場所 |
| --- | --- | --- |
| surface | `#fffdf3` | ページの地（クリーム） |
| card | `#ffffff` | 記事の本文エリア、サイドバーのカード |
| ink | `#262b33` | 本文・見出しの文字、カードの線と影（真っ黒は使わない） |
| ink-logo | `#3d4f63` | ブログタイトル、ロゴ（クリームの上で 8.3:1） |
| ink-muted | `#5d6570` | 日付、カテゴリ以外の補足、キャプション |
| link | `#58708a` | リンク（下線は消さない） |
| rule | `#e6e1cf` | 区切り線、表の線 |

アプリの色（そのアプリの話のときだけ）

| アプリ | 色 | 白い文字を載せたとき | 元 |
| --- | --- | --- | --- |
| 発破職人ブーモル | `#58708a` | 5.1:1 | デザインシステム（0-1 の要確認） |
| てくてくダイヤリー | `#23855c` | 4.6:1 | tekuteku サポートページのリンク色 |
| 駅間アラーム | `#3f766d` | 5.2:1 | デザインシステム（ekikan のリンク色） |
| 駅間アラームの金 | `#a88a4f` | 飾り専用（文字には使わない） | ベルの色の代わり |

### 文字

サポートページと同じ 3 つの Google Fonts を使います。はてなブログのデザイン CSS の先頭で `@import` すれば、無料プランでも読み込めます。

| 用途 | フォント | 太さ・大きさ |
| --- | --- | --- |
| ブログタイトル | Zen Kaku Gothic New | 900 / 28px / 字間 0.04em / `#3d4f63` |
| ロゴ「MORK STUDIO」（画像の中だけ） | Dela Gothic One | 400 / 字間 0.04em / `#3d4f63` |
| 記事タイトル・見出し | Zen Kaku Gothic New | 900 |
| 本文 | Zen Kaku Gothic New | 400 / 16px / 行間 1.9 |
| ブログの説明文、カードの一言説明 | M PLUS Rounded 1c | 400 |

- Dela Gothic One は「MORK STUDIO」の英字だけに使います。漢字がつぶれるので、「開発記」や記事タイトル、見出しには使いません。ブログタイトル「MORK STUDIO 開発記」は 1 つの文字列で、CSS では途中から書体を変えられないため、全体を Zen Kaku Gothic New 900 にします。
- 本文の行間はサポートページ（1.8）より少し広い 1.9 にします。長い文を読ませるためです。

### 雰囲気

- **くっきり、でも静か。** 地はクリーム、文字は炭色。目立たせたいものだけ「黒い線＋ぼかさない影」のカードにします（サポートページのヒーローカードと同じ形）。
- **角丸は 14px だけ。** ボタンなどの小さいものは 10px。
- **影はぼかさない。** `4px 4px 0 #262b33` のような、ずらした影だけを使います。
- **使わないもの**：グラデーション、絵文字の飾り、左に色の線がついたカード、パステル。

## 2. ヘッダー

**バナー画像は入れない。** ブログタイトルを文字のロゴとして見せます。

- 無料プランではヘッダーそのものは消せません。そこで CSS で、ブログタイトルを Zen Kaku Gothic New 900 の `#3d4f63`、ブログの説明文を M PLUS Rounded 1c の `#5d6570` にします。
- 説明文はひとことで、たとえば「モークと AI のチームが、iPhone アプリをつくる開発記。」。
- 画像にしない理由：文字のほうがスマホで速く表示され、検索にも読まれます。アクセスが 3 件の今は、記事の中身とアイキャッチに力を使うほうが効果的です。
- あとでバナーを入れる場合は、アイキャッチと同じ作り（クリーム地、黒い線、アプリ 3 色の小さなタイル）にして、高さは 160px 以下にします。

## 3. サイドバー「MORK STUDIO のアプリ」欄

HTML は `docs/blog/sidebar-apps.html`、見た目の CSS は `hatena-design.css` に入っています。

- カード 1 枚＝アプリ 1 つ。白い地、`#262b33` の 2px の線、角丸 14px、影 `3px 3px 0 #262b33`。
- 左にアプリアイコン（56×56px、角丸 12px）、右にアプリ名（Zen Kaku Gothic New 900、16px）と一言説明（M PLUS Rounded 1c、13px）。
- その下に「App Store で見る」ボタン。地はそのアプリの色、文字は白、角丸 10px。カードの中でアプリの色が出るのはここだけです。
- 並び順：ブーモル → てくてくダイヤリー → 駅間アラーム（スタジオトップと同じ）。
- アイコン画像は、はてなフォトライフに上げて、その URL を `src` に入れてください（HTML の中の `ICON_URL_…` を置きかえます）。App Store の URL も同じく `APPSTORE_URL_…` を置きかえます。

## 4. アイキャッチ画像のテンプレート（1200×630）

テンプレートは `docs/blog/eyecatch-template.html`、見本は `docs/blog/eyecatch-sample.png` です。ファイルの先頭の `DATA`（タイトル、アプリ、日付）を書きかえてブラウザで開き、1200×630 で画面を保存すれば画像になります。

構成

- 地：クリーム `#fffdf3`。外側に 40px の余白。
- 中央に、白いカード（線 6px `#262b33`、角丸 28px、影 `10px 10px 0 #262b33`）。サポートページのヒーローカードを大きくした形です。
- カードの左上：`MORK STUDIO 開発記`（28px、`#3d4f63`。「MORK STUDIO」は Dela Gothic One、「開発記」は Zen Kaku Gothic New 900）。
- カードの中央：記事タイトル（Zen Kaku Gothic New 900、60px、行間 1.35、最大 3 行、`#262b33`）。長いタイトルは、テンプレートが自動で 52px → 44px に縮めます。
- カードの下：アプリの色の帯（高さ 72px）に、白でアプリ名（Zen Kaku Gothic New 900、28px）。右端に日付（M PLUS Rounded 1c）。
- アプリと関係ない回（体制の話など）は、帯を `#3d4f63`（スタジオの色）にして「MORK STUDIO」と書きます。
- 駅間アラームの回だけ、帯の右上に金 `#a88a4f` の小さな丸を 1 つ置きます（ベルの代わり）。
- 写真やスクショは入れません。タイトルの文字で読ませます。一覧に並んだとき、アプリの色の帯で何の回かがわかるようにするためです。

## 5. 記事中の画像・図の決まり

### 図（体制図、流れ図など）

- 地は白かクリーム。四角は白い地に `#262b33` の 2px の線、角丸 14px、影 `4px 4px 0 #262b33`。
- 矢印と線は `#262b33` の 2px。点線は使わない。
- 人や役割の色分けは、アプリの色を使います（例：ブーモル担当の Claude は `#58708a`）。人（モーク）は `#3d4f63`、まとめ役（master）は白地に太い線で区別します。色だけでなく、名前も必ず書きます。
- 文字は Zen Kaku Gothic New。見出しは 900、ほかは 400。図の中の文字は 20px（画像の幅 1200px のとき）以上。
- 横幅 1200px で作り、記事にはそのまま入れます（CSS で幅いっぱいに縮みます）。
- グラデーション、立体、影のぼかしは使いません。

### スクリーンショット

- iPhone の画面は、端末の枠を付けずにそのまま使います。CSS で角丸 24px と `#262b33` の 2px の線を付け、横幅は最大 320px にして中央に置きます（`hatena-design.css` の `.mork-shot`）。
- 2 枚を並べて比べるときは、横に並べます（スマホでは縦に並びます）。
- 説明は画像のすぐ下に、`#5d6570` の 13px で 1 行書きます。
- 個人の情報（位置、名前、通知）は、ぼかさずに黒い四角で隠します。

## 6. CSS の使い方（ブロガーさんへ）

- `docs/blog/hatena-design.css` の中身を、はてなブログの「デザイン」→「カスタマイズ」→「デザイン CSS」に貼ってください。正は今までどおり、ブロガーさん側の `settings/hatena-design.css` です。そちらに取り込んでから貼ってください。
- 書いた前提：テーマは標準テーマ（Boilerplate 系のクラス名）。違うテーマの場合は、効かない部分があります。
- スクショには、記事の HTML 編集で `<figure class="mork-shot">…</figure>` を使ってください。
